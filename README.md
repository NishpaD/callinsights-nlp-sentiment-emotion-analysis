# CallInsights: NLP-Based Sentiment and Emotion Analysis Dashboard

## Description

CallInsights is an NLP-based Streamlit dashboard that analyzes customer service call transcripts to identify customer sentiment, detect emotions, and generate useful service insights. The system allows users to upload transcript data, process the text, view interactive visualizations, analyze agent performance, and export reports.

This project focuses on converting unstructured customer service text into structured insights that can support customer satisfaction monitoring, quality assurance, and data-driven decision-making.

## Objectives

- Analyze customer service call transcripts using NLP techniques
- Classify customer sentiment as Positive, Negative, or Neutral
- Detect customer emotions such as Happiness, Anger, Sadness, Frustration, and Fear
- Identify patterns in customer experience and service quality
- Support agent performance analysis through dashboard insights
- Provide downloadable reports for further analysis and documentation

## Dataset

This project uses a dummy CSV dataset created for testing and validation. No real customer data or personally identifiable information is used.

Key Attributes:

- Transcript text
- Agent
- Call status
- Duration
- Waiting time
- Time bucket

The system can also be adapted for real customer service transcript datasets in the future, provided that the data is anonymized and used with permission and ethical approval.

## Features

- CSV file upload and validation
- Text cleaning and preprocessing
- Sentiment analysis using TextBlob
- Keyword-based emotion detection
- Interactive dashboard with KPIs and charts
- Sentiment and emotion distribution analysis
- Agent performance analysis
- Time-based call analysis
- Report generation and CSV export
- User-friendly Streamlit interface

## Key Insights

The dashboard helps identify:

- Overall customer sentiment distribution
- Most common customer emotions
- Negative and positive interaction patterns
- Agents with higher positive or negative call rates
- Call trends based on time-related fields
- Resolution rate and operational performance indicators
- Areas where customer service quality can be improved
